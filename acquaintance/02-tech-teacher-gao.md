# 古衡实掌管科技活动的神

这篇文章要介绍的是一名老师，他叫郭燕，任职于衡实现教处，同时兼任微机课老师。

我和郭燕老师的认识，还要始于一次年级大会活动。

高一时的一次年级大会，年级部派遣我到学校礼堂的中控室，协助进行大屏控制和声音控制等。那次在礼堂中控负责这次活动的现教处老师，正是郭燕老师。我在大会活动中，和郭燕老师聊天，得知她经常组织学校的科技活动，也算是第一次认识了。

后来一次与郭燕老师见面，就是在我的高一下学期，开了一门计算机课，是郭燕老师带我们班，教 Python 语言，她还记得我，我和这位老师就算是熟识了。

再后来，她也经常在我们年级宣传一些科技类竞赛和活动，我出于翘课的目的，也经常愿意去参加这些活动和比赛。郭燕老师也是在**整个学校内**组织这类活动和比赛最频繁的老师之一，她自己有个社团，叫机器人社团，跟她参加比赛的多是她自己社团的成员，但我是个例外。在我高一刚入学军训的时候，她的社团曾在我们年级开过宣讲会，但我没有去听，毕竟我自己对“机器人”的兴趣是不及“计算机”的。

在郭燕老师的社团里，我遇到了比我小一届的灿和 hissin。后来，我们一起参加过郭老师带队的一些比赛，也成为了非常要好的朋友。
